# Workflow de collaboration

1. Partir de `main` à jour.
2. Créer une branche dédiée à une seule fonctionnalité.
3. Tester la fonctionnalité avant intégration.
4. Documenter l’API si le backend est concerné.
5. Faire un commit ciblé et ouvrir une demande d’intégration.
6. Vérifier l’intégration frontend/backend avant de passer à la fonctionnalité suivante.

Ne jamais supprimer ou modifier une API validée ni une migration utilisée sans accord des deux développeurs.
